# Detail Page Columns

A layout prototype for a detail page header with adaptive two-column layout.

**Live demo:** https://adamhindman.github.io/detail-page-columns/

## Layout

The header uses a two-column grid (equal widths, 40px gap) with a description on the left and a properties list on the right. If the columns become too unbalanced, the layout switches to a stacked single-column view.
