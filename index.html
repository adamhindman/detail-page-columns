Layout strategy

The detail header has two layouts: side-by-side, where the description and properties sit in equal-width columns with a 40px gap, and stacked, where the description appears on top and the properties below in a single column.

Adaptive stacking

After the page renders, we measure the pixel height of both columns and compute the ratio as left ÷ right. If the ratio falls below a threshold, the layout switches to the stacked layout. The left column includes everything in the description area: the text, the "Show more" button if present, and the scorecard if present.

Line clamping

The description is clamped to a set number of lines. The ratio is calculated against the clamped height. Expanding via "Show more" does not affect the layout decision.

Prototype note

In this prototype, the layout can toggle between side-by-side and stacked as you adjust the controls. Because the description column is full-width in stacked mode, its height would be shorter than in side-by-side mode, making a naive height comparison unreliable. To work around this, the ratio is always measured in side-by-side mode: before measuring, the stacked class is temporarily removed, heights are read (forcing a synchronous reflow), and the class is re-added if needed. No paint occurs between these steps, so there is no visible flash.

In production this is unnecessary. The layout is determined once on page load, always starting in side-by-side mode, and never changes after that.
