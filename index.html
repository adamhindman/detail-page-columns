Layout strategy

The detail header has two layouts: side-by-side, where the description and properties sit in equal-width columns with a 40px gap, and stacked, where the description appears on top and the properties below in a single column.

Adaptive stacking

After the page renders, we measure the pixel height of both columns and compute the ratio as left ÷ right. If the ratio falls below a threshold, the layout switches to the stacked layout.

Line clamping

The description is clamped to a set number of lines. The ratio is calculated against the clamped height. Expanding via "Show more" does not affect the layout decision.

Prototype note

In this prototype, the layout can switch between side-by-side and stacked as you adjust the controls. When the layout is already stacked, the description column is full-width and therefore shorter than it would be in side-by-side mode. To keep the ratio calculation meaningful, we double the stacked description height as a rough estimate of its side-by-side height.

In production this adjustment is unnecessary, since the layout is determined once on page load and does not change.
